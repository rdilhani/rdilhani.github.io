# 🖥️ Introduction to Programming with C\#

C# (pronounced *C Sharp*) is a powerful programming language developed by Microsoft. It is used to build many types of applications such as desktop software, web applications, mobile apps, and even games.

The best thing about C# is that it is **easy to learn** if you are just starting programming.

---

## 🔹 Your First C# Program

Every C# program starts with a **class** and a **Main method**.
Here’s the simplest program:

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello, World!");
    }
}
```

### 👉 Explanation:

* `using System;` → Allows us to use basic commands like `Console.WriteLine`.
* `class Program` → Every C# code is inside a class (here the class is called **Program**).
* `static void Main()` → The starting point of the program.
* `Console.WriteLine("Hello, World!");` → Prints text on the screen.

When you run this, the output will be:

```
Hello, World!
```

---

## 🔹 Working with Variables

A variable is like a container that stores data. For example:

```csharp
using System;

class Program
{
    static void Main()
    {
        int age = 20;
        string name = "Alice";

        Console.WriteLine("Name: " + name);
        Console.WriteLine("Age: " + age);
    }
}
```

### 👉 Output:

```
Name: Alice
Age: 20
```

Here:

* `int` → stores numbers (like 10, 20, 100).
* `string` → stores text (like “Alice”).

---

## 🔹 Taking Input from the User

You can ask the user to enter data:

```csharp
using System;

class Program
{
    static void Main()
    {
        Console.Write("Enter your name: ");
        string name = Console.ReadLine();

        Console.WriteLine("Hello, " + name + "!");
    }
}
```
